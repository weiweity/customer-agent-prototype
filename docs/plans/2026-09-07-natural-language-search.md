## 可验收行为

以下均为合成例子，定义后续实现目标，不宣称当前实现已支持。

| 查询与候选关系 | 预期行为 | 例子 |
| --- | --- | --- |
| 关键词、完整问句或无歧义错字表达同一需求 | 可展示相关原文 | 完整询问清洗步骤 → 清洗方法 |
| 问题较宽，候选附有明确条件 | 可展示并保留全部条件 | 退货运费 → 符合指定条件才免运费 |
| 输入与候选明确冲突 | 拒绝该候选 | 买两件送四件 ≠ 买四件送两件 |
| 商品或操作不同 | 拒绝该候选 | 更换纸张 ≠ 更换墨盒 |
| 上下文不足，无法确定相关需求 | 无结果或澄清 | 这个东西怎么办 |
| 来源、有效期或授权范围不合格 | 现有门禁拒绝 | 已撤销来源、过期、跨平台或商品范围 |

新的合成验收集须在运行前冻结规则、输入与期望；保留明确冲突和条件相关候选两类对照。旧实验与真实50题均不改写、不重新算作PASS。若冻结期望与新规则冲突，报告差异，由业务复核建立新版本，禁止实现者事后改题美化结果。

| 方案 | 判断依据 | 结论 |

所有者与最小接口：数据库拥有来源、发布、平台、商品范围和有效期门禁；API搜索模块拥有相关性与冲突判断；卡片展示原文与适用场景；客服核对条件。复用现有 `SearchBackend`、`SearchRepository` 和Top3候选合同。模型参数、缓存与来源绑定不泄漏给renderer，不新增桌面Node权限或通用IPC。

失败路径：损坏权重、加载失败、超时、异常数值须明确失败，不静默包装为正常无结果。若未来引入模型缓存，必须绑定模型及不可变内容版本，并在返回前复核当前来源；不能重新引入已撤销内容。相关性分数不能证明业务条件满足。
